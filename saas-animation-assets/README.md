# GRASYA SaaS Motion Assets

This directory is generated by `node export-script/generate-assets.mjs` from the repository root. It is isolated from the production application and adds no runtime dependencies.

The generator creates a manifest, design-system notes, a local HTML preview catalogue, atomic SVGs, composite widgets, and a representative Migration Monitor scene. Each asset records source paths, dimensions, states, and limitations.

## Current extraction scope

The first pass contains a primary button, connected status badge, progress track, migration-flow widget, Object Explorer tree, and representative Migration Monitor scene. The live ERD graph, relationship-mapping panel, full connection wizard states, live logs, and all dynamic data states are not yet exported. Static equivalents are explicitly labelled in the manifest and catalogue.

## After Effects

Import SVGs through File → Import → File. For path-level animation, use Create Shapes from Vector Layer and inspect the converted groups. SVG groups do not automatically become separate AE timeline layers, and SVG text is not guaranteed to become native editable text. Confirm fonts, clipping, and strokes on the target machine.

Run `npm run build` separately to validate the production application; the generator does not change the app entry points or build configuration.
